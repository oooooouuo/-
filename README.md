//遇到过的一些问题及解决方法

·硬件连接问题
缺乏硬件相关知识，根据说明书加自学完成硬件部分

·引脚配置问题，不知该如何配置引脚不知道电机具体型号以至于对每个轮子的正反转测试迟迟未通过
查阅rosmasterx3官方资料，在控制电机的正转反转教程文字版找到了电机原理图及不同电机对应的引脚

·电脑无法与小车建立连接
烧录及串口助手的波特率设置错误，后统一设置成115200波特率

·烧录测试不知具体如何操作
在AI的建议下先是尝试了st-link v2，b站学习如何连接到小车，但是st-link v2与电脑的连接不稳定，在成功烧录过几次后便不再能成功与电脑建立连接，后经查阅资料，
选择仅通过usb连接小车通过stm32cubeprogrammer烧录，coolterm测试，，使用st-link v2可以避免仅使用usb连接小车和电脑遇到的烧录测试后需断开连接重新与串口助手建立连接的切换问题
但由于不稳定，最终选择方案二。

·测试整机运动时按下回车键之后小车与coolterm瞬间断开连接又迅速自动重连
先是关闭DTR，RTS，没有效果，后打开扩展板开关，能够恢复正常进行测试，故障原因应是电力不足
